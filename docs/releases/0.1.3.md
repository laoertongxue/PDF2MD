# PDF2MD 0.1.3 - M0 Reliability Baseline

## 中文

本版本收口桌面应用、无人值守 OCR 和发布流程的 M0 可靠性基线。它是后续商业化里程碑的工程基础，不是商业 GA 版本。

### 本次更新

- 强化桌面 Sidecar 生命周期：随机本地端口、通过继承文件描述符传递会话令牌、受控启停与重启、退出时回收后代进程，以及有界且脱敏的日志。
- 强化 OCR 状态恢复：旧状态迁移、崩溃恢复和最终 Markdown 发布继续采用失败关闭策略，不因恢复失败静默降低精读质量。
- 固定 Python、Node、Rust 和前端依赖工具链，增加 Python、前端、Rust、架构、安全及发布资产的统一质量门禁。
- 强化 macOS Apple Silicon 发布资产检查：校验 Sidecar 冷启动、本地鉴权、Mach-O 架构、开发路径和凭据泄漏、代码签名完整性及 DMG 内实际应用。
- GitHub Release 同时提供 DMG、App ZIP、SHA-256 校验文件和同一次 workflow run 生成的来源证明。

### 重要限制

- 当前仅发布 macOS 13 及以上的 Apple Silicon 客户端。
- 应用仍为 ad-hoc 签名，尚未使用 Apple Developer ID，也未完成 Apple 公证。首次打开可能需要在 Finder 中选择“打开”或在“系统设置”中允许打开。
- 这是 M0 工程基线，不是中国大陆商业首发版本；中英文界面切换、正式签名、公证、许可与商业运营能力仍属于后续里程碑。
- Codex CLI 必须配置为安全、可直接执行且非符号链接的文件。需要百度 OCR 复核的页面若未配置凭据会稳定阻断，不会降低质量后继续发布。
- 进程在外部 OCR 请求返回前被强制终止时，该请求可能在恢复后重复执行；持久状态和最终发布必须保持幂等，但不能宣称第三方调用 exactly-once。

## English

This release closes the M0 reliability baseline for the desktop app, unattended OCR, and the release pipeline. It is an engineering foundation for later commercial milestones, not a commercial GA build.

### Changes

- Hardened the desktop sidecar lifecycle with a random loopback endpoint, inherited-file-descriptor session tokens, controlled stop and restart behavior, descendant process cleanup, and bounded redacted logs.
- Hardened OCR state recovery. Legacy migration, crash recovery, and final Markdown publication remain fail-closed instead of silently lowering reading quality.
- Pinned the Python, Node, Rust, and frontend toolchains and added unified Python, frontend, Rust, architecture, security, and release-asset gates.
- Strengthened macOS Apple Silicon asset checks for sidecar cold start, local authentication, Mach-O architecture, development-path and credential leaks, code-signature integrity, and the actual app mounted from the DMG.
- GitHub Releases include the DMG, App ZIP, SHA-256 files, and provenance generated by the same workflow run.

### Important Limitations

- The current client supports Apple Silicon on macOS 13 or later.
- The app remains ad-hoc signed. It does not yet use an Apple Developer ID and is not notarized. The first launch may require Finder's **Open** action or **Open Anyway** in System Settings.
- This is an M0 engineering baseline, not the mainland China commercial launch build. Chinese/English UI switching, production signing and notarization, licensing, and commercial operations remain later milestones.
- Codex CLI must be configured as a secure direct executable, not a symlink. Pages that require Baidu OCR adjudication fail closed when its credentials are unavailable.
- If the process is forcibly terminated before an external OCR request returns, recovery may repeat that request. Durable state and final publication are idempotent, but third-party calls are not claimed to be exactly-once.
